Aplicación: Refugio de Animales

Esta aplicación permite gestionar un refugio de animales mediante una interfaz gráfica desarrollada en Java Swing y conectada a una base de datos mediante Hibernate.

1. Inicio de la aplicación

  1. Ejecute la aplicación.
  2. Se abrirá la ventana principal denominada Refugio de Animales.
  3. La interfaz está organizada en cuatro pestañas principales.

2. Gestión de Animales

Pestaña: 🐾 Animales

  • Registrar nuevos animales.
  • Modificar datos existentes.
  • Eliminar registros.
  • Consultar animales almacenados.
  • Asignar medicamentos.
  • Adjuntar fotografía del animal.

Datos principales:

  • ID
  • Nombre
  • Edad
  • Especie
  • Raza
  • Estado
  • Medicamentos asociados
  • Fotografía

3. Gestión de Medicinas

Pestaña: 💊 Medicinas

  • Crear medicamentos.
  • Editar información.
  • Eliminar medicamentos.
  • Consultar el listado disponible.

Información gestionada:

  • ID
  • Nombre
  • Tipo
  • Descripción

4. Gestión de Clientes

Pestaña: 👤 Clientes

  • Registrar adoptantes.
  • Actualizar datos.
  • Eliminar clientes.
  • Consultar registros.

Datos almacenados:

  • ID
  • Nombre
  • DNI
  • Teléfono
  • Correo electrónico
  • Dirección (calle, número, ciudad y código postal)

5. Gestión de Adopciones

Pestaña: 🏠 Adopciones

  • Registrar adopciones.
  • Seleccionar cliente y animal.
  • Guardar fecha de adopción.
  • Añadir observaciones.
  • Consultar el historial de adopciones.

6. Operaciones habituales

AcciónProcedimiento
Crear registroCompletar los campos y pulsar el botón de guardar.
Modificar registroSeleccionar un elemento, editar los datos y guardar cambios.
Eliminar registroSeleccionar el elemento y pulsar eliminar.
Consultar datosUtilizar las tablas de cada pestaña.

7. Validaciones

La aplicación utiliza validaciones para comprobar que los datos introducidos sean correctos antes de almacenarlos en la base de datos.

8. Cierre de la aplicación

Para finalizar, cierre la ventana principal utilizando el botón de cierre del sistema.
